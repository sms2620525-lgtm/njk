일을 맡길 수 있는 네 가지 조건

챗봇은 질문에 답하고, 에이전트는 일을 끝냅니다. Hermes가 후자에 가까운 이유는 아래 네 가지가 학습 단계부터 들어가 있기 때문입니다.

  1. 손이 있다
    도구 사용     함수 호출과 도구 사용을 Atropos 환경에서 별도로 훈련했습니다. 검색·DB·사내 API를 직접 호출합니다.
  2. 서식을 지킨다
    스키마 준수     Pydantic 기반 JSON 생성과 150가지 이상의 출력 포맷을 정확히 지키도록 보상했습니다. 뒷단 시스템에 그대로 꽂힙니다.
  3. 맥락을 쥔다
    131K 컨텍스트     계약서 묶음, 코드베이스, 회의록 몇 달치를 한 번에 올려두고 다단계 작업을 이어갑니다.
  4. 안에 있다
    자체 호스팅     가중치가 공개돼 외부 API로 자료를 보내지 않아도 됩니다. 규제 산업에서는 이게 결정적입니다.

Hermes 4 405B는 미국 수학경시(AIME) 문제에서 추론을 켜면 100점 만점에 81.9점을 받습니다. 그럼 똑같은 모델이 추론만 껐을 때는 몇 점일까요?

▸ 하나를 골라보세요

정답은 D — 11.4점입니다. 가중치도, 파일도, 크기도 완전히 같은 모델입니다. 달라진 건 “먼저 생각하고 답해라”는 지시 한 줄뿐인데 70점이 날아갑니다.

그래서 인터넷에서 본 AI 점수는 항상 어떤 조건에서 잰 건지 확인해야 합니다. 같은 모델이 순위표 1등도, 중위권도 될 수 있으니까요.

어디서 구하고, 어떻게 부르나

잠깐 — API란?

API(Application Programming Interface)는 프로그램끼리 대화하는 창구입니다. 식당 주문 창구를 떠올리면 쉽습니다. 손님은 주방에 직접 들어가지 않고, 창구에 정해진 형식으로 주문서를 내밀고 음식을 받습니다.

AI에서도 같습니다. 내 프로그램이 정해진 형식으로 질문을 보내면, 상대 서버가 모델을 돌려 답을 돌려줍니다. 주방(모델)이 어떻게 생겼는지 몰라도 창구 규칙만 알면 쓸 수 있다는 게 핵심입니다. 그래서 앞에서 본 것처럼 호출하는 쪽 언어가 무엇이든 상관없습니다.

팁 · Hermes는 시스템 프롬프트를 강하게 따릅니다. 성격·말투·금지사항을 여기에 자세히 적을수록 결과가 크게 달라집니다.
주의 · 추론 토글은 기본이 꺼짐인 경우가 많습니다. 수학·논리 작업이라면 반드시 켜세요.

비판적으로

그럼 단점은 없나

사실성

기억이 부정확하다

SimpleQA 25.8. 추론은 강해도 사실 회상은 약합니다. 검색·사내 문서 연결 없이 지식 업무를 맡기면 위험합니다.

해석

96.2%는 조건부

추론을 켰을 때 값입니다. 기본 꺼짐으로 배포하면 같은 모델이 순위표에서 훨씬 낮게 나옵니다.

지표

자체 제작 벤치마크

RefusalBench는 Nous가 만들고 채점 기준도 정했습니다. 유리하게 설계됐을 가능성을 배제할 수 없습니다.

비용

초기 투자가 든다

405B는 GPU 클러스터가 필요합니다. 대부분의 팀에게 현실적인 선택지는 70B 이하입니다.

기반

바닥부터 만든 게 아니다

사전학습은 Llama 3.1과 Qwen3에 기대고 있습니다. 사후 학습의 성과로 읽는 편이 정확합니다.

운영

손이 많이 간다

추론 토글, 양자화, 서빙 엔진 선택까지 직접 정해야 합니다. 켜자마자 쓰는 서비스와는 다릅니다.
