맡기려면

일을 맡길 수 있는 네 가지 조건

챗봇은 질문에 답하고, 에이전트는 일을 끝냅니다. Hermes가 후자에 가까운 이유는 아래 네 가지가 학습 단계부터 들어가 있기 때문입니다.

  1. 손이 있다
    도구 사용     함수 호출과 도구 사용을 Atropos 환경에서 별도로 훈련했습니다. 검색·DB·사내 API를 직접 호출합니다.
  2. 서식을 지킨다
    스키마 준수     Pydantic 기반 JSON 생성과 150가지 이상의 출력 포맷을 정확히 지키도록 보상했습니다. 뒷단 시스템에 그대로 꽂힙니다.
  3. 맥락을 쥔다
    131K 컨텍스트     계약서 묶음, 코드베이스, 회의록 몇 달치를 한 번에 올려두고 다단계 작업을 이어갑니다.
  4. 안에 있다
    자체 호스팅     가중치가 공개돼 외부 API로 자료를 보내지 않아도 됩니다. 규제 산업에서는 이게 결정적입니다.

▸ 하나를 골라보세요

정답은 D — 11.4점입니다. 파일도 크기도 완전히 같은 모델입니다. 달라진 건 “먼저 생각하고 답해라”는 지시 한 줄뿐인데 70점이 날아갑니다.

그래서 인터넷에서 본 AI 점수는 항상 어떤 조건에서 잰 건지 확인해야 합니다. 같은 모델이 순위표 1등도, 중위권도 될 수 있으니까요.

잠깐 — API란?

API(Application Programming Interface)는 프로그램끼리 대화하는 창구입니다. 식당 주문 창구를 떠올리면 쉽습니다. 손님은 주방에 직접 들어가지 않고, 창구에 정해진 형식으로 주문서를 내밀고 음식을 받습니다.

AI에서도 같습니다. 내 프로그램이 정해진 형식으로 질문을 보내면, 상대 서버가 모델을 돌려 답을 돌려줍니다. 주방(모델)이 어떻게 생겼는지 몰라도 창구 규칙만 알면 쓸 수 있다는 게 핵심입니다. 그래서 앞에서 본 것처럼 호출하는 쪽 언어가 무엇이든 상관없습니다.
